# 作業タイマー＋OBPM 工数自動入力 (PowerShell 版) README

ノート PC で作業時間を記録し、デスクトップ PC が SI Object Browser PM (以下 OBPM) の工数入力画面に自動で入力する。
**Windows 標準の PowerShell 5.1 だけで動く** (Python などのインストールは不要)。

```
[ノート PC]                       [ファイルサーバー]                [デスクトップ PC (常時起動)]
作業タイマー (worktimer)  ──▶  records.csv (作業記録)   ──▶  自動入力 (obpm_input・待機モード)
 タスク選択・開始・終了           input_request.json (依頼)        依頼に気づいたら OBPM を起動して入力
 「本日終了」で入力を依頼          obpm_input_status.json (結果) ◀──  依頼があれば数分以内に入力
```

## 事前確認: PowerShell スクリプトを実行できるか (両方の PC)

PowerShell で次を実行する。

```powershell
Get-ExecutionPolicy -List
```

- `MachinePolicy` と `UserPolicy` が両方 `Undefined` なら問題なし (bat の中で一時的に実行を許可して起動する)
- どちらかに `Restricted` や `AllSigned` などが設定されている場合は、**会社の設定でスクリプトの実行が制限されている**。情報システム部門に相談する

## ファイルの置き場所

| 置き場所 | ファイル |
|---|---|
| ノート PC | `worktimer.bat` / `worktimer.ps1` / `common.ps1` / `worktimer.ini` / `tasks.csv` |
| デスクトップ PC | `obpm_input.bat` / `obpm_input.ps1` / `common.ps1` / `obpm_input.ini` |
| ファイルサーバー | 作業記録などのフォルダ (例: `\\fileserver\share\worktimer\data`)。両方の PC から読み書きできること |

`common.ps1` は両方の PC に必要 (共通の部品)。

## セットアップ

### 1. 共有フォルダを決める
- ノートの `worktimer.ini` の `data_dir` と、デスクトップの `obpm_input.ini` の `data_dir` に、**同じ共有フォルダ**を書く

### 2. タスク一覧 (tasks.csv) を作る
1. デスクトップで自動ログインを登録しておく (下の「自動ログイン」。登録していない場合は OBPM の工数入力画面を開いておく)
2. `obpm_input.bat` を実行し、**2 (タスク一覧の候補を作る)** を選ぶ (読み取りのみ。1〜2 分かかる。終わるまで触らない)
   - 読み取り中に OBPM 以外の画面が手前に来て位置が分からなくなった場合は、検索語なしで検索し直して最初から 1 回だけ読み直す
3. 共有フォルダにできる `tasks_candidates.csv` を Excel で開き、使うタスクの行だけを残してノートの `tasks.csv` に貼る
   - **タスク名**は自由に変えてよい。**プロジェクトコード**と **WBS** は変えない
   - WBS が「親 > 子」の形になっているものは、同じ名前の WBS が別の親の下にもあるもの

### 3. 試運転 (デスクトップ)
`obpm_input.ini` の `mode` を段階的に切り替えて確認する。ノートで少し作業を記録してから、`obpm_input.bat` → **1 (今すぐ入力する)** で実行する。

| 段階 | mode | 内容 | 確認すること |
|---|---|---|---|
| ① | `check` | 入力先のセルを探して現在の値を読むだけ (入力しない) | ログで、各タスクの行・日付が正しいか |
| ② | `manual` | 入力して読み返すまで。**更新は押さずに止まる** | 画面で値が正しいセルに入っているか。自分で「更新」を押したときに確認メッセージが出るか |
| ③ | `live` | 入力・読み返し・更新まで自動 | ― (本番) |

- ② で値が入らない・ずれる場合は、`[obpm]` の `commit_key` (確定キー) と `after_commit` (確定後に選択が動く方向) を画面の動きに合わせる
- ③ では、更新後の確認メッセージ「更新します。よろしいですか？」にも自動で「はい」を押す

### 自動ログイン (デスクトップ)
OBPM は**起動していなくてよい**。入力のたびにツールが OBPM の状態を見て、必要なら「起動 → ログイン → 工数入力を開く」を自動で行う。
また、OBPM は開いたままにすると開いた日の日付のままになり今日の列に入力できないため、日付がずれていたら「× で閉じる → 起動し直す → ログイン」を自動で行う。

1. `obpm_input.bat` → **6** を選び、ログインアカウントとパスワードを入力する
   - パスワードはこのフォルダの `obpm_login.dat` に**暗号化**して保存される (Windows の機能。この PC のこのユーザーでしか読めない)。ini や共有フォルダには保存しない
   - 登録の最後に、見つかった OBPM の場所が表示される。「見つかりませんでした」と出たら、`obpm_input.ini` の `obpm_exe` に OBPM の実行ファイルの場所を書く
   - パスワードを変更したら、もう一度 **6** で登録する。削除は **7**
2. ログインに失敗したら、**アカウントのロックを防ぐため、登録し直すまで自動ではログインしない** (ログに理由が出る)

OBPM の場所は ① ini の `obpm_exe` → ② 前に動いていた OBPM の場所 (`obpm_launcher.txt` に自動で記録) → ③ スタートメニュー・デスクトップのショートカット → ④ Program Files の順に探す。
自動ログインを登録していない場合は、OBPM を自分で起動・ログインして工数入力画面を開いておく (日付がずれていると入力せずに止まり、ノートに「要ログイン」と出る)。

### 4. 待機モードを PC 起動時に起動する (デスクトップ)
`obpm_input.bat` → **4 (PC 起動時に自動で起動するよう登録する)** を選ぶ。
次回のサインインから、画面に何も表示されないまま待機モードが動く。今すぐ起動するときは **3** を選ぶ。

待機モードの動き:
- 数分ごと (既定 5 分) に「本日終了」の依頼を確認し、あれば入力する (定時の自動入力はしない。`times` に時刻を書けば、その時刻にも入力する)
- 画面がロックされている間は保留し、ロック解除後に入力する
- 動作状況は共有フォルダの `obpm_input_log.txt` で確認できる
- 止めるときは PC を再起動するか、タスクマネージャーで該当の「Windows PowerShell」を終了する (登録の解除は **5**)

### 5. 作業タイマーを PC 起動時に起動する (ノート)
1. `Win + R` → `shell:startup` と入力して Enter
2. `worktimer.bat` のショートカットをそのフォルダに入れる

## 毎日の使い方 (ノート)

1. 画面の右下の**小さい画面**でタスクを選び「開始」→ 作業が終わったら「停止」 (別のタスクを開始すると前のタスクは自動で終了)
   - 小さい画面はマウスが離れていると半透明になる。「画面」ボタンで大きい画面 (集計・記録修正・本日終了) を開閉する
   - アプリの終了は小さい画面の ×。大きい画面の × は隠すだけ
   - タスクの一覧は**最近作業した順**に並ぶ (一度も作業していないタスクは tasks.csv の順で後ろ)
2. 開始を押し忘れた・時間を直したいときは、大きい画面の「**記録修正**」
   - 日付を選ぶとその日の記録が一覧に出る。記録を選んで「修正」「削除」、または内容を入れて「追加」
   - 修正できるのは今月分だけ。ほかの記録と時間が重なる場合は確認が出る。変更前の記録は `records.csv.bak` に残る
   - 変更は、次に「本日終了」を押したときに OBPM へ入力される
3. 帰るときに大きい画面の「**本日終了**」を押す → デスクトップが数分以内にまとめて入力する
   - 作業時間の合計が 7.75H に足りないときは確認が出る (早退などで問題なければ「はい」)
   - **月末 (月の最後の営業日以降)** は、本日分は自動入力しない (OBPM で自分で確認・入力する)。前日までの未入力分は自動で入力する
   - 本日終了を押さずにアプリを閉じようとすると確認が出る
4. 次にタイマーを起動したとき、次の場合は確認が出る
   - 本日終了が押されていない日がある (シャットダウンで閉じた日など) → 入力を依頼するか選ぶ
   - 前回の自動入力が完了していない (エラー・保留など) → もう一度依頼するか選ぶ
5. 大きい画面の一番下に、デスクトップの**前回の自動入力の結果**が表示される

## 入力の仕組みと安全策

- **1 日の合計を社内ルールに合わせる** (`obpm_input.ini` の `[daily_total]`)
  - 各タスクは 15 分単位で四捨五入。丸めて 0 になる短いタスクは 0.25H として計上する
  - 終わった日 (前日以前、または「本日終了」を押した日) は、合計を「定時 7.75H + 残業 (0.5H 未満は切り捨て)」にする。例: 記録 8:00 → 7.75H / 8:30 → 8.25H / 9:00 → 8.75H
  - ずれは一番長く作業したタスクで増減する。調整した内容はログに `[合計]` で出る
  - 記録の合計が 7.75H 未満の日は調整せず、ログに記録漏れの確認を促すメッセージを出す
- その日のそのタスクの**合計時間で上書き**する。前回入力した値と同じものは入力しない (何回実行しても同じ結果)
- 本日終了を押し忘れた日は、次に本日終了を押したときにまとめて入力される (今月分に限る)
- **月末の営業日以降の日は自動入力しない** (土日・祝日・`holidays.csv` の日を除いた月の最後の日。ログに `[月末]` と出る)
- **前月分は自動入力しない** (ログに「手入力してください」と出る)
- 入力後にセルを読み返し、**全件が合っていたプロジェクトだけ「更新」**を押す。合わない場合は更新せずに止まる
- WBS が見つからないタスクは入力せずにログに残す (`tasks.csv` の WBS 名を確認)
- 同じ名前の WBS が続く場合は、一番下 (一番深い) 行に入力する
- OBPM 以外のウィンドウが手前に来たら、その時点で止まる (誤入力防止)
- 「入力完了」のチェックには触らない (月末の締めは人が行う)

## 結果の確認 (共有フォルダ)

| ファイル | 内容 |
|---|---|
| `obpm_input_log.txt` | 自動入力のログ (何をどこに入力したか、見つからない・確認できない項目) |
| `obpm_input_status.json` | 前回の結果 (ノートのタイマー画面に表示される)。「要ログイン」と出たら、デスクトップで OBPM にログインする (ログイン後、数分以内に自動で入力される) |
| `obpm_input_state.json` | 入力済みの値 (削除すると、次回すべて入力し直す) |
| `closed_days.json` | 「本日終了」を押した日の一覧 (この日は合計を調整して入力する) |
| `records.csv` | 作業記録 (Excel で修正してよい。修正後は閉じる)。`records.csv.bak` は記録修正の前の内容 |
| `holidays.csv` | 会社独自の休日 (任意。1 列目に日付 `2026-12-30` を 1 行に 1 日。祝日は自動で判定するので書かなくてよい) |
| `error.log` | 作業タイマーで起きたエラーの記録 |

## 設定

### ノート (`worktimer.ini`)
| 項目 | 内容 |
|---|---|
| `data_dir` | 共有フォルダ |
| `idle_stop_min` | この分数だけ操作がなければ、最後に操作した時刻で自動停止 (既定 10。0 で無効) |
| `mini_window` / `mini_opacity` | 小さい画面を使うか / マウスが離れているときの不透明度 (既定 0.5) |
| `base_hours` | 定時の工数 (既定 7.75)。本日終了のとき、これに足りなければ確認する |
| `round_unit_min` / `round_mode` | 集計画面の丸め (既定: 15 分単位で四捨五入) |
| `launch_obpm` / `obpm_exe` | タイマー起動時に OBPM も起動するか、その実行ファイルのパス |

### デスクトップ (`obpm_input.ini`)
| 項目 | 内容 |
|---|---|
| `data_dir` | 共有フォルダ (ノートと同じ) |
| `mode` | `check` / `manual` / `live` (上の「試運転」参照) |
| `round_unit_min` / `round_mode` | 丸め (**ノートと同じ値にする**) |
| `times` / `request_check_min` | 自動実行の時刻 (既定: 空 = 本日終了のときだけ) / 依頼を確認する間隔。変えたら待機モードを起動し直す (PC 再起動など) |
| `input_method` | 入力欄・ボタンの操作方法。`mouse` (既定) / `message` (マウスを使わない。リモートデスクトップを最小化して使うとき) |
| `commit_key` / `after_commit` | セルに数値を打った後の確定キー / 確定後に選択が動く方向 |
| `key_wait` / `search_wait` | キー操作の間隔 / 検索後の待ち時間 (動作が不安定なら大きくする) |

## 注意

- `.bat` は **ANSI (Shift_JIS)** で保存すること。UTF-8 だと文字化けして動かない
- `.ps1` を編集したら **UTF-8 (BOM 付き)** で保存すること (メモ帳の「名前を付けて保存」→ 文字コード「UTF-8 (BOM 付き)」)。BOM がないと日本語が文字化けして動かない
- `.ini` は UTF-8 で保存する。`tasks.csv` は UTF-8 / Shift_JIS (Excel の通常の CSV 保存) のどちらでもよい
- 自動ログインを登録していれば、デスクトップの OBPM は開いていなくてよい。登録していない場合は**ログインして工数入力画面を開いたまま**にしておく
- 自動入力の実行中 (数十秒〜数分) は、デスクトップのキーボードとマウスに触らない
- デスクトップは、入力するときに**画面が使える状態**である必要がある (ロック中・リモートデスクトップ切断中は入力を保留し、使えるようになったら入力する)
- リモートデスクトップで接続して使う場合は、**接続したまま最小化**しておけば入力できる。そのための設定:
  1. ノート側 (接続する側) で次を実行し、リモートデスクトップを開き直す
     `reg add "HKCU\Software\Microsoft\Terminal Server Client" /v RemoteDesktop_SuppressWhenMinimized /t REG_DWORD /d 2 /f`
  2. デスクトップの `obpm_input.ini` で `input_method = message` にして、待機モードを起動し直す
